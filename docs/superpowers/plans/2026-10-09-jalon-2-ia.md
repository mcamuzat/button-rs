# Jalon 2 — Jouer contre l'IA : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un joueur affronte une IA (Facile, Normal, Difficile) dans le navigateur, sans serveur : l'IA tourne en WASM dans un Web Worker et ne voit que ce qu'un joueur peut voir.

**Architecture:** Nouvelle crate `crates/ai` : `observe` retire l'information cachée (choix Swing adverse non révélé, futurs jets), `evaluate` note une position, `quick_action` + `rollout` simulent une manche, `choose_action` fait un expectimax échantillonné (profondeur 1 ou 2 selon le niveau). `engine-wasm` expose `ai_choose_action(stateJson, …)`. Côté client, un `AiAdapter` (même interface `GameAdapter` que le hotseat) envoie l'état au Worker quand c'est au tour de l'IA.

**Tech Stack:** Rust (crate `buttonmen-ai`, serde, ts-rs optionnel), wasm-bindgen =0.2.121, Web Worker (Vite, format ES), React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-09-buttonmen-rs-design.md` (§7 IA, §9 Client)

## Global Constraints

- L'IA ne lit jamais l'information cachée : le choix Swing/Option adverse non révélé et l'état du RNG (`observe` les retire avant toute simulation).
- `fn choose_action(state, player, level, seed) -> Option<Action>` choisit parmi `candidate_actions` ; déterministe pour une graine donnée.
- Niveaux : `Easy` (glouton, une seule couche), `Normal` (profondeur 1 + chance), `Hard` (profondeur 2, plus d'échantillons).
- Le moteur porte toute la logique ; le client ne fait qu'envoyer l'état au Worker et appliquer l'action rendue.
- Le joueur humain est le siège `One`, l'IA le siège `Two`.
- Interface en français ; niveaux affichés « Facile », « Normal », « Difficile ».
- Commits conventionnels terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Pas de Tilt dans ce dépôt : cargo et pnpm se lancent directement.

## Review Focus

1. **Choix Swing simultanés** : quand l'humain a déjà validé sa Swing, l'IA décide exactement comme s'il ne l'avait pas fait. → test `does_not_read_the_opponents_hidden_swing` (Tâche 1).

```rust
use buttonmen_engine::{GameState, PlayerId, SeededRng, WaitingFor};

/// What `me` may know of `state` (spec §7):
/// - the opponent's unrevealed Swing/Option choice is forgotten (R 3.1), and the
///   opponent is asked again, so simulations sample it instead of reading it;
/// - the random generator is replaced by one seeded with `seed`, so future rolls are unknown.
pub fn observe(state: &GameState, me: PlayerId, seed: u64) -> GameState {
    let mut seen = reseeded(state, seed);
    let opponent = me.other();
    if seen.player_mut(opponent).pending_choice.take().is_some() {
        if let WaitingFor::SpecifyDice { pending } = &mut seen.waiting_for {
            if !pending.contains(&opponent) {
                pending.push(opponent);
            }
        }
    }
    seen
}

/// A copy of `state` whose future rolls come from `seed`.
pub fn reseeded(state: &GameState, seed: u64) -> GameState {
    let mut copy = state.clone();
    copy.rng = SeededRng::new(seed);
    copy
}
```

```rust
use buttonmen_engine::{
    AttackKind, DeclaredAttack, Die, DieSkill, GameState, PlayerId, WaitingFor, check_attack,
    round_score,
};

const MATCH_WON: f64 = 1.0e9;
/// One round of lead is worth more than any score difference within a round.
const ROUND_WON: f64 = 1000.0;
/// A threat is not a capture yet.
const THREAT_WEIGHT: f64 = 0.5;

/// How good `state` is for `me` (spec §7): match lead first, then the current round's
/// score difference (half-points), then what each side threatens to capture next.
pub fn evaluate(state: &GameState, me: PlayerId) -> f64 {
    let opponent = me.other();
    if let WaitingFor::GameOver { result } = &state.waiting_for {
        return if result.winner == me { MATCH_WON } else { -MATCH_WON };
    }
    let wins = |p: PlayerId| f64::from(state.player(p).record.wins);
    let rounds = wins(me) - wins(opponent);
    let score = f64::from(round_score(state, me) - round_score(state, opponent));
    let threat = threat(state, me) - threat(state, opponent);
    rounds * ROUND_WON + score + THREAT_WEIGHT * threat
}

/// Half-points that capturing `target` swings towards the capturer (R 5.1): it leaves
/// its owner's kept dice (half its size) and joins the capturer's pile (its full size).
/// A Poison die swings the other way (R 6.7).
pub fn capture_gain(target: &Die) -> f64 {
    let size = f64::from(target.max());
    if target.has(DieSkill::Poison) { -3.0 * size } else { 3.0 * size }
}

/// The best single-die capture `side` could make next (Power or Shadow): a cheap
/// stand-in for the full attack list.
fn threat(state: &GameState, side: PlayerId) -> f64 {
    let mut best = 0.0_f64;
    for attacker in &state.player(side).active {
        for target in &state.player(side.other()).active {
            for kind in [AttackKind::Power, AttackKind::Shadow] {
                let attack = DeclaredAttack { kind, attackers: vec![attacker.id], targets: vec![target.id] };
                if check_attack(state, side, &attack).is_ok() {
                    best = best.max(capture_gain(target));
                }
            }
        }
    }
    best
}
```

```rust
use buttonmen_engine::{
    Action, AttackKind, DeclaredAttack, GameState, LegalActions, PlayerId, SeededRng, SpecChoice,
    WaitingFor, apply, candidate_actions, legal_actions,
};

use crate::eval::{capture_gain, evaluate};
use crate::observe::reseeded;

/// Bounds a rollout even in a round that would never end.
const MAX_ROLLOUT_STEPS: usize = 400;

/// What `attack` is expected to swing towards `player` (spec §7, greedy move ordering).
/// A Trip only captures sometimes: half its gain.
pub fn attack_gain(state: &GameState, player: PlayerId, attack: &DeclaredAttack) -> f64 {
    let defender = state.player(player.other());
    let gain: f64 = attack
        .targets
        .iter()
        .filter_map(|&id| defender.die(id))
        .map(capture_gain)
        .sum();
    if attack.kind == AttackKind::Trip { gain / 2.0 } else { gain }
}

/// A cheap move (spec §7, "politique gloutonne"): the attack with the best immediate
/// gain; a random Swing/Option choice; the first reserve die; let the opponent start.
/// `None` when `player` has nothing to do.
pub fn quick_action(state: &GameState, player: PlayerId, rng: &mut SeededRng) -> Option<Action> {
    match legal_actions(state, player) {
        LegalActions::Wait | LegalActions::GameOver => None,
        LegalActions::SpecifyDice { swing, options } => Some(Action::SpecifyDice {
            choice: SpecChoice {
                swing: swing
                    .iter()
                    .map(|r| {
                        let span = u64::from(r.max - r.min) + 1;
                        (r.letter, r.min + (rng.next_u64() % span) as u8)
                    })
                    .collect(),
                options: options.iter().map(|o| (o.die, if rng.coin() { o.a } else { o.b })).collect(),
            },
        }),
        LegalActions::ChooseReserve { dice } => Some(Action::ChooseReserve { die: dice.first().copied() }),
        LegalActions::ReactToInitiative { .. } => Some(Action::PassInitiative),
        LegalActions::Attack { attacks, can_pass } => {
            if can_pass {
                return Some(Action::Pass);
            }
            // Prefer attacks that need no Fire; a Fire-only position is completed below.
            let best = |needs_fire: bool| {
                attacks
                    .iter()
                    .filter(|o| o.needs_fire == needs_fire)
                    .max_by(|a, b| {
                        attack_gain(state, player, &a.attack).total_cmp(&attack_gain(state, player, &b.attack))
                    })
                    .map(|o| Action::Attack { attack: o.attack.clone() })
            };
            best(false).or_else(|| best(true))
        }
        LegalActions::AdjustFire { .. } => {
            let candidates = candidate_actions(state, player);
            candidates
                .iter()
                .find(|a| matches!(a, Action::FireTurnDown { .. }))
                .or_else(|| candidates.first())
                .cloned()
        }
    }
}

/// Plays `state` forward with `quick_action` until the round changes or the match ends,
/// then evaluates it for `me` (spec §7: Swing sizes are judged on simulated rounds).
pub fn rollout(state: &GameState, me: PlayerId, seed: u64) -> f64 {
    let mut rng = SeededRng::new(seed);
    let mut current = reseeded(state, seed ^ 0x5EED);
    let start = current.round;
    for _ in 0..MAX_ROLLOUT_STEPS {
        if matches!(current.waiting_for, WaitingFor::GameOver { .. }) || current.round != start {
            break;
        }
        let Some(&actor) = current.actors().first() else { break };
        let Some(action) = quick_action(&current, actor, &mut rng) else { break };
        match apply(&current, actor, action) {
            Ok((next, _)) => current = next,
            Err(_) => break,
        }
    }
    evaluate(&current, me)
}
```

```rust
/// Plays a whole match, each seat driven by `choose_action` at its level; returns the winner.
fn play(a: usize, b: usize, levels: [Level; 2], seed: u64) -> PlayerId {

        [button("A", pool[a].clone()), button("B", pool[b].clone())],
        seed,
        MatchConfig::default(),
    );
    for step in 0..3000u64 {
        if let WaitingFor::GameOver { result } = state.waiting_for {
            return result.winner;
        }
        let actor = state.actors()[0];
        let level = levels[actor.index()];
        let action = choose_action(&state, actor, level, seed.wrapping_add(step)).expect("an actor has an action");

}
```

```rust
use buttonmen_engine::{
    Action, GameState, LegalActions, PlayerId, SeededRng, WaitingFor, apply, candidate_actions,
    legal_actions,
};
use serde::{Deserialize, Serialize};

use crate::eval::evaluate;
use crate::observe::{observe, reseeded};
use crate::policy::{attack_gain, rollout};

/// Strength of the AI (spec §7).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[cfg_attr(feature = "ts", derive(ts_rs::TS), ts(export))]
pub enum Level {
    /// Greedy: one layer, one sample; random choices before the round.
    Easy,
    /// Depth 1 with chance: several samples of the rolls; rollouts before the round.
    Normal,
    /// Depth 2: the opponent's best reply is considered; more samples and rollouts.
    Hard,
}

struct Params {
    /// Samples of the rerolls per candidate (chance nodes).
    samples: u32,
    /// Simulated rounds per candidate before the round starts (Swing, Reserve, initiative).
    rollouts: u32,
    /// 1: my move; 2: my move and the opponent's best reply.
    depth: u8,
    /// Opponent replies examined at depth 2, best immediate gain first.
    replies: usize,
}

impl Level {
    fn params(self) -> Params {
        match self {
            Level::Easy => Params { samples: 1, rollouts: 0, depth: 1, replies: 0 },
            Level::Normal => Params { samples: 4, rollouts: 6, depth: 1, replies: 0 },
            Level::Hard => Params { samples: 6, rollouts: 12, depth: 2, replies: 10 },
        }
    }
}

/// Picks `me`'s action (spec §7): sampled expectimax over `candidate_actions`, seen
/// through `observe` (no hidden information). Deterministic for a given `seed`.
pub fn choose_action(state: &GameState, me: PlayerId, level: Level, seed: u64) -> Option<Action> {
    let seen = observe(state, me, seed);
    let mut candidates = candidate_actions(&seen, me);
    if candidates.len() <= 1 {
        return candidates.pop();
    }
    let params = level.params();
    let mut rng = SeededRng::new(seed ^ 0xA11CE);
    let before_round = matches!(
        seen.waiting_for,
        WaitingFor::SpecifyDice { .. } | WaitingFor::ChooseReserve { .. } | WaitingFor::ReactToInitiative { .. }
    );
    if before_round && params.rollouts == 0 {
        let pick = (rng.next_u64() % candidates.len() as u64) as usize;
        return Some(candidates.swap_remove(pick));
    }
    let mut best: Option<(Action, f64)> = None;
    for action in candidates {
        let runs = if before_round { params.rollouts } else { params.samples };
        let mut total = 0.0;
        for _ in 0..runs {
            let sample = reseeded(&seen, rng.next_u64());
            total += match apply(&sample, me, action.clone()) {
                Ok((next, _)) if before_round => rollout(&next, me, rng.next_u64()),
                Ok((next, _)) if params.depth >= 2 => reply_value(&next, me, params.replies, &mut rng),
                Ok((next, _)) => evaluate(&next, me),
                // Candidates are legal by construction; a refusal only scores as worst.
                Err(_) => f64::MIN / 2.0,
            };
        }
        let value = total / f64::from(runs);
        if best.as_ref().is_none_or(|(_, v)| value > *v) {
            best = Some((action, value));
        }
    }
    best.map(|(action, _)| action)
}

/// Depth 2: when the opponent attacks next, `me` gets the worst value among its most
/// promising replies (best immediate gain first, plus passing when allowed).
fn reply_value(state: &GameState, me: PlayerId, replies: usize, rng: &mut SeededRng) -> f64 {
    let opponent = me.other();
    if state.waiting_for != (WaitingFor::Attack { player: opponent }) {
        return evaluate(state, me);
    }
    let LegalActions::Attack { attacks, can_pass } = legal_actions(state, opponent) else {
        return evaluate(state, me);
    };
    let mut ordered: Vec<_> = attacks.into_iter().filter(|o| !o.needs_fire).map(|o| o.attack).collect();
    ordered.sort_by(|a, b| attack_gain(state, opponent, b).total_cmp(&attack_gain(state, opponent, a)));
    let mut options: Vec<Action> =
        ordered.into_iter().take(replies).map(|attack| Action::Attack { attack }).collect();
    if can_pass {
        options.push(Action::Pass);
    }
    if options.is_empty() {
        return evaluate(state, me);
    }
    options
        .into_iter()
        .map(|reply| {
            let sample = reseeded(state, rng.next_u64());
            apply(&sample, opponent, reply).map_or_else(|_| evaluate(state, me), |(next, _)| evaluate(&next, me))
        })
        .fold(f64::INFINITY, f64::min)
}
```

```ts
export function applyAction(
  engine: EngineMatch,
  player: PlayerId,
  action: Action,

  let outcome: ApplyOutcome;
```

```ts
import type { Action } from "../engine/generated/Action";
import type { Level } from "../engine/generated/Level";
import type { PlayerId } from "../engine/generated/PlayerId";

export interface AiRequest {
  stateJson: string;
  player: PlayerId;
  level: Level;
  seed: number;
}

/** Where the AI's moves come from (a Web Worker in the app, a fake in tests). */
export interface AiBrain {
  think(request: AiRequest): Promise<Action | null>;
  dispose(): void;
}

/** Messages between `WorkerBrain` and `ai.worker.ts`. */
export type WorkerRequest = AiRequest & { id: number };
export type WorkerResponse = { id: number; actionJson: string | null } | { id: number; error: string };

/** Runs the engine's AI in a Web Worker, so the page stays responsive while it thinks. */
export class WorkerBrain implements AiBrain {
  private readonly worker = new Worker(new URL("./ai.worker.ts", import.meta.url), { type: "module" });
  private readonly pending = new Map<number, { resolve: (a: Action | null) => void; reject: (e: Error) => void }>();
  private nextId = 0;

  constructor() {
    this.worker.onmessage = (event: MessageEvent<WorkerResponse>) => {
      const answer = event.data;
      const waiter = this.pending.get(answer.id);
      if (!waiter) return;
      this.pending.delete(answer.id);
      if ("error" in answer) waiter.reject(new Error(answer.error));
      else waiter.resolve(answer.actionJson === null ? null : (JSON.parse(answer.actionJson) as Action));
    };
  }

  think(request: AiRequest): Promise<Action | null> {
    const id = this.nextId++;
    return new Promise((resolve, reject) => {
      this.pending.set(id, { resolve, reject });
      this.worker.postMessage({ ...request, id } satisfies WorkerRequest);
    });
  }

  dispose(): void {
    this.worker.terminate();
    this.pending.clear();
  }
}
```

```ts
import type { Action } from "../engine/generated/Action";
import type { Level } from "../engine/generated/Level";
import type { PlayerId } from "../engine/generated/PlayerId";
import type { AiBrain } from "../ai/brain";
import { applyAction, viewAs } from "./engine";
import type { EngineMatch, GameAdapter, Snapshot } from "./GameAdapter";

const HUMAN: PlayerId = "One";
const AI: PlayerId = "Two";

export function levelLabel(level: Level): string {
  switch (level) {
    case "Easy":
      return "Facile";
    case "Normal":
      return "Normal";
    case "Hard":
      return "Difficile";
  }
}

const randomSeed = () => crypto.getRandomValues(new Uint32Array(1))[0];

/** The human (seat One) against the engine's AI (seat Two), which runs in a worker. */
export class AiAdapter implements GameAdapter {
  readonly handoff = false;
  readonly names: Record<PlayerId, string>;
  private snapshot: Snapshot;
  private readonly listeners = new Set<() => void>();
  private disposed = false;

  constructor(
    private readonly engine: EngineMatch,
    private readonly brain: AiBrain,
    private readonly level: Level,
    private readonly nextSeed: () => number = randomSeed,
  ) {
    this.names = { One: "Vous", Two: `IA (${levelLabel(level)})` };
    this.snapshot = { view: viewAs(engine, { type: "Seat", player: HUMAN }), lastEvents: [], version: 0, thinking: false, failure: null };
    this.askAiIfNeeded();
  }

  getSnapshot = (): Snapshot => this.snapshot;

  subscribe = (listener: () => void): (() => void) => {
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  };

  dispatch(player: PlayerId, action: Action): string | null {
    const error = this.play(player, action);
    if (error === null) this.askAiIfNeeded();
    return error;
  }

  dispose(): void {
    this.disposed = true;
    this.brain.dispose();
    this.engine.free();
  }

  private play(player: PlayerId, action: Action): string | null {
    const outcome = applyAction(this.engine, player, action);
    if ("error" in outcome) return outcome.error;
    this.update({
      view: viewAs(this.engine, { type: "Seat", player: HUMAN }),
      lastEvents: outcome.events,
      version: this.snapshot.version + 1,
    });
    return null;
  }

  private update(change: Partial<Snapshot>) {
    this.snapshot = { ...this.snapshot, ...change };
    this.listeners.forEach((listener) => listener());
  }

  /** When the AI must act (the engine lists it among the actors), ask the brain. */
  private askAiIfNeeded() {
    if (this.disposed || this.snapshot.thinking || !this.snapshot.view.actors.includes(AI)) return;
    this.update({ thinking: true });
    this.brain
      .think({ stateJson: this.engine.state_json(), player: AI, level: this.level, seed: this.nextSeed() })
      .then((action) => {
        if (this.disposed) return;
        this.update({ thinking: false });
        if (action === null) return;
        const error = this.play(AI, action);
        if (error !== null) this.update({ failure: error });
        else this.askAiIfNeeded();
      })
      .catch((e: unknown) => {
        if (this.disposed) return;
        this.update({ thinking: false, failure: e instanceof Error ? e.message : String(e) });
      });
  }
}
```
